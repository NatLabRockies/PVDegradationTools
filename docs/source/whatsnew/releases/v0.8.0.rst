v0.8.0 (XXXX-XX-XX)
===================

Breaking Changes
----------------
- Change ``Scenario.addJob`` to ``addJob(func, name=None, depends_on=None)``. The
  ``func_kwarg`` argument is removed; pass extra keyword arguments in a
  ``(function, kwargs)`` tuple instead. ``Scenario`` also no longer changes the working
  directory, and ``Scenario.load_json()`` no longer reuses the output directory saved
  in the json file. (:pull:`382`)


Enhancements
------------
- Extend the Scenario framework to run multi-step analyses. Jobs can be named and
  chained so that one job's output is passed to a later job (``depends_on``), bound to
  one material layer of a multi-material module, and written to an output directory
  set with ``PVDEG_JOB_PATH`` or ``pvdeg.config.SCENARIO_OUTPUT_PATH``. (:pull:`382`)


Bug Fixes
---------
- Fix ``Scenario`` instances sharing one default pipeline, ``Scenario.run()`` dropping
  ``pd.Series`` results or failing when job kwargs overlap automatically supplied
  arguments, and the deprecated pandas ``"H"`` frequency alias in
  ``pvdeg.weather.repeat_annual_time_series()``. (:pull:`382`)


Documentation
-------------
- Update the ``04_scenario`` tutorials to the new ``Scenario.addJob`` API.
  (:pull:`382`)
